# 生成、登记、比较

当用户要求新图或变体，且宿主提供 image_gen 工具时，使用宿主图像生成能力。先生成或确认参考对象，再带参考图生成变体；修改前需看过参考图。固定身份特征，只改计划变量。不假设相同提示词保证同一物体。

保留实际提示词与工具返回的输出文件；参数和模型名未披露时写 UNDISCLOSED，不能猜测。将图片复制到项目目录，再用 scripts/register_generation.py 登记；该脚本只记录输入声明，不自动证明来源。只有观察到实际工具回执并比对输出，才能另行记录已核实生成来源及其范围。

登记后运行 build_gallery.py 与 review_gallery.py。AI目视意见放 notes，正式人工验收保持 needs_review，直到使用者确实验收；不要把自动检查或AI意见冒充人工验收。

本次 examples/generated-mug 是实际生成的参考图与换场景变体；模型名未披露，未声称其为商业产品或精确物体身份验证。独立Python环境没有宿主生图工具时，用户可提供已有输出，或另行配置并授权生成服务；不伪造 GENERATED。
